Where Every Pet Belongs.

Live Demo ↗GitHub ↗

A pet-first social and care platform where the pet has the public identity. I built the application end to end with profiles, posts, social activity, play dates, reminders, privacy controls, persistence and production deployment.

Java 17Spring BootPostgreSQLREST APIsJavaScriptDockerRender
Problem

Pet social life, care and memories are usually scattered across separate tools, while most products treat the pet as just a record owned by a person.

Solution

I designed a persistent pet identity with an owner account behind it, then connected social feeds, profiles, care features and account controls through Spring Boot APIs and PostgreSQL.

Trade-off

I chose a strong monolithic prototype over premature distributed services, cloud object storage and event infrastructure so the complete product could be built and tested first.

Next

V2 would add cloud image storage, real-time messaging, stronger local discovery, observability and deeper end-to-end automation.

DATA + LLM

LLM Text Chunking

GitHub ↗
PythonText ProcessingLLM

Problem: long unstructured text becomes noisy or too large for useful model context.

Solution: clean and divide content into context-friendly chunks for downstream prompting.

Trade-off: smaller chunks improve manageability but can separate related context.

Next: compare fixed, sentence-aware and semantic chunking using retrieval-quality measurements.

APPLIED AI

Prompt Chain Extraction

GitHub ↗
TransformersFLAN-T5Prompt Design

Problem: one large prompt can become unreliable when extracting several kinds of information.

Solution: split the task into smaller chained prompts and pass structured context forward.

Trade-off: clearer task separation costs more latency and can propagate earlier mistakes.

Next: add schema validation and benchmark chained extraction against a single-prompt baseline.
